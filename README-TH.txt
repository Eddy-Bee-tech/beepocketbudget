BeePocketBudget – Public Release 3.0.0
สมุดบัญชีรายรับ–รายจ่ายสำหรับเกษตรกรผู้เลี้ยงผึ้ง

สิ่งที่มีในรุ่นนี้ (ต่อยอดจาก PWA 2.2.2):
- Dashboard รายรับ รายจ่าย และยอดสุทธิ
- เพิ่ม แก้ไข ลบ และกรองประวัติรายการ
- รายงานรายเดือน/รายปี และกราฟ 12 เดือน
- วิเคราะห์รายได้และค่าใช้จ่ายตามหมวดหมู่ พร้อมตัวชี้วัดทางการเงิน
- พิมพ์รายงาน / บันทึก PDF ผ่านเมนูพิมพ์ของอุปกรณ์หรือเบราว์เซอร์
- สำรอง JSON และกู้คืนแบบรวมรายการหรือแทนที่ข้อมูลเดิม
- จัดเก็บข้อมูลใน localStorage ของเบราว์เซอร์บนอุปกรณ์
- Service Worker cache สำหรับเปิดแอปออฟไลน์หลังโหลดครั้งแรก
- manifest และไอคอนสำหรับติดตั้งบนหน้าจอหลัก
- เอกสารคู่มือผู้ใช้ภาษาไทย และนโยบายความเป็นส่วนตัวภาษาไทย

ไฟล์หลัก:
- index.html: หน้าจอแอป
- app.js: ฟังก์ชันบัญชีและรายงาน
- manifest.webmanifest: ข้อมูลติดตั้ง PWA
- sw.js: cache/offline
- icons/: ไอคอนแอป
- คู่มือผู้ใช้-ไทย.txt: คู่มือ iPhone/Android
- PRIVACY-TH.html: นโยบายความเป็นส่วนตัว

การเผยแพร่บน GitHub Pages:
1. แตก ZIP
2. เข้า repository https://github.com/Eddy-Bee-tech/beepocketbudget
3. อัปโหลด/แทนที่ไฟล์และโฟลเดอร์ทั้งหมดภายใน BeePocketBudget-PWA ไปไว้ที่ root ของ repository (อย่าอัปโหลดโฟลเดอร์ชั้นนอกซ้อนอีกชั้น)
4. Commit changes ไปยัง branch main
5. รอ GitHub Pages deploy แล้วเปิด https://eddy-bee-tech.github.io/beepocketbudget/
6. ทดสอบบน iPhone Safari และ Android Chrome ก่อนประกาศใช้งาน

คำเตือนการอัปเดต:
- สำรองข้อมูล JSON จากทุกอุปกรณ์ก่อนอัปเดต
- การเปลี่ยนไฟล์แอปไม่ควรลบ localStorage แต่ควรทดสอบและมีไฟล์สำรองเสมอ
- Service Worker ใช้ cache ชื่อใหม่ beepocketbudget-public-v3 เพื่อให้ดึงไฟล์รุ่นนี้

ข้อจำกัดสำคัญ:
- ไม่มีระบบบัญชีผู้ใช้ ไม่มี backend และไม่มี cloud sync
- ข้อมูลของ iPhone/Android และแต่ละ browser profile แยกจากกัน
- หากล้างข้อมูลเว็บไซต์/เบราว์เซอร์ เปลี่ยนอุปกรณ์ หรือรีเซ็ตเครื่อง อาจสูญเสียข้อมูลที่ไม่ได้สำรอง
- Offline ใช้ได้หลังเข้าครั้งแรกและแคชไฟล์ครบแล้ว; การติดตั้ง/อัปเดต/เปิดครั้งแรกต้องใช้อินเทอร์เน็ต
- PDF เป็นการใช้เมนูพิมพ์ของ browser/device; ผลลัพธ์อาจต่างกันตามอุปกรณ์

สถานะการทดสอบ:
- ตรวจ syntax JavaScript ด้วย Node.js ก่อนส่งมอบ
- ต้องทดสอบจริงบน iPhone และ Android หลัง deploy โดยเฉพาะ install, backup, restore, report/print และ offline
- รุ่นนี้เป็น Public Release Candidate สำหรับทดสอบก่อนเผยแพร่ทั่วไป ไม่ใช่การรับรองความปลอดภัยหรือการตรวจสอบจากหน่วยงานอิสระ
