BeePocketBudget PWA รุ่นทดลอง 2.1.0

สิ่งที่มี:
- Dashboard รายรับ รายจ่าย ยอดคงเหลือ
- เพิ่ม แก้ไข ลบ และกรองประวัติรายการ
- รายงานรายเดือน/รายปี และกราฟ 12 เดือน
- พิมพ์รายงาน / บันทึก PDF ผ่านเมนูพิมพ์ของอุปกรณ์
- สำรองและกู้คืน JSON
- เก็บข้อมูลใน localStorage ของอุปกรณ์
- Service Worker สำหรับ cache ไฟล์และเปิดแบบออฟไลน์หลังเข้าครั้งแรก

วิธีทดลองบนเครื่องคอมพิวเตอร์:
1. แตก ZIP
2. เปิดโฟลเดอร์ด้วย VS Code หรือใช้ static server
3. ต้องเปิดผ่าน HTTPS หรือ localhost เพื่อให้ Service Worker ทำงาน
4. ห้ามเปิด index.html ด้วยการดับเบิลคลิกแล้วคาดหวังว่า offline cache จะทำงานครบ

ติดตั้งบน iPhone:
1. อัปโหลดไฟล์ทั้งหมดขึ้น static hosting ที่ให้ HTTPS (เช่น GitHub Pages)
2. เปิด URL ด้วย Safari บน iPhone
3. กด Share > Add to Home Screen > Add
4. เปิดจากไอคอน BeePocketBudget
5. เข้าเว็บครั้งแรกขณะออนไลน์ก่อน เพื่อให้ไฟล์ถูก cache จากนั้นทดสอบโหมดเครื่องบิน

ข้อควรทราบ:
- PWA ไม่ใช่แอป Native ใน App Store แต่ติดตั้งไอคอนบนหน้าจอหลักได้
- ไม่ต้องเปิด Expo/คอมพิวเตอร์เป็น server หลังติดตั้งและ cache สำเร็จ
- ไม่ต้องเชื่อมต่อ backend หรือ cloud; ข้อมูลอยู่ใน browser storage ของเครื่องนั้น
- การลบข้อมูลเว็บไซต์/ลบไอคอนหรือเปลี่ยนอุปกรณ์อาจทำให้ข้อมูลหาย ควรสำรอง JSON เป็นประจำ
- การโฮสต์ครั้งแรกต้องมี HTTPS; บริการ hosting ฟรีอาจมีเงื่อนไข/โควตาตามผู้ให้บริการ
- เวอร์ชันนี้เป็นการแปลงจาก source ที่ได้รับ ยังควรทดสอบฟังก์ชันและการนำเข้าไฟล์ JSON เดิมก่อนใช้งานจริง
