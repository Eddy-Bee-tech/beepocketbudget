นโยบายความเป็นส่วนตัว

BeePocketBudget รุ่น Public Release 3.0.0

BeePocketBudget เป็นสมุดบัญชีสำหรับบันทึกรายรับและรายจ่ายของเกษตรกรผู้เลี้ยงผึ้ง

1. การจัดเก็บข้อมูล

รายการบัญชีที่ผู้ใช้บันทึกจะถูกเก็บไว้ในพื้นที่จัดเก็บของเว็บเบราว์เซอร์บนอุปกรณ์ที่ใช้งาน แอปเวอร์ชันนี้ไม่มีระบบบัญชีผู้ใช้และไม่มีฐานข้อมูลบนเซิร์ฟเวอร์สำหรับรับรายการบัญชี

2. การส่งข้อมูล

แอปไม่ส่งรายการบัญชีไปยังผู้พัฒนาโดยอัตโนมัติ ผู้ใช้เป็นผู้สั่งส่งออกไฟล์สำรอง JSON เอง และเลือกสถานที่จัดเก็บหรือช่องทางส่งต่อด้วยตนเอง

3. การซิงก์ข้ามอุปกรณ์

ข้อมูลใน iPhone และ Android แยกจากกัน ไม่มีการซิงก์อัตโนมัติ หากต้องการย้ายข้อมูลให้ส่งออกไฟล์ JSON จากอุปกรณ์ต้นทาง แล้วนำเข้าในอุปกรณ์ปลายทาง

4. ความรับผิดชอบในการสำรองข้อมูล

ผู้ใช้ควรสำรองไฟล์ JSON เป็นประจำและเก็บไว้ในสถานที่ปลอดภัย การล้างข้อมูลเว็บไซต์ เปลี่ยนเบราว์เซอร์ รีเซ็ตเครื่อง หรือทำอุปกรณ์สูญหายอาจทำให้ข้อมูลที่ยังไม่ได้สำรองสูญหาย

5. การใช้งานออฟไลน์

แอปสามารถเปิดไฟล์ที่แคชไว้ได้เมื่อเคยโหลดแอปขณะออนไลน์แล้ว การใช้งานบางอย่าง เช่น การเปิดเว็บไซต์ครั้งแรกหรือการอัปเดต อาจต้องใช้อินเทอร์เน็ต

6. การเปลี่ยนแปลงนโยบาย

หากมีการเพิ่มระบบออนไลน์ การวิเคราะห์การใช้งาน หรือการเก็บข้อมูลรูปแบบอื่น จะต้องปรับปรุงนโยบายนี้ให้สอดคล้องก่อนเปิดใช้คุณสมบัติดังกล่าว

เอกสารนี้อธิบายพฤติกรรมของรุ่น Public Release 3.0.0 ตามโค้ดที่จัดส่ง ไม่ใช่คำรับรองทางกฎหมายหรือการตรวจสอบความปลอดภัยจากหน่วยงานอิสระ
